OpenClustered Package Expansion

Abstract: The original OpenClustered package addressed a need for a clustered data repository similar to OpenML or the Penn Machine Learning Benchmark for use in benchmark comparison studies. This repository would decrease time spent finding, cleaning, and formatting data which often resulted wasted and duplicated efforts. It began with 19 publically available datasets with binary outcomes from various domains. The expansion to the OpenClustered package included the addition of 11 clustered datasets with continuous outcomes sourced from R packages, and package updates compatible with both classification and regression tasks.

  • Searched linear mixed model tutorials, R packages, and open-source data repositories for continuous clustered datasets with at least four features
  • Engineered an R pipeline for visualizing and summarizing the meta-data characteristics - number of observations, number of features, number of clusters, imbalance
  • Presented to a faculty, peers, researcheres across the domains of biomedical engineering, bioinformatics, biostatistics, and machine learning

Presentation: OpenClustered Presentation (PDF)

OpenLong Harmonization

Background: OpenLong is a project aimed at creating a harmonized dataset combining multiple longitudinal aging studies to faciliate data sharing. Again with the idea that it would reduce time spent searching for datasets siloed on differenct websites, and time spent formatting and processing the same datasets. At this point the project was in its very early stages with only three health datasets (HABC, CHS, and ARIC) waiting to be integrated.

  • Verified each dataset's chosen variable documentation accurately measured the pre-determined overarching description
  • Suggested a unified coding for each variable to be used across all three datasets, taking care to retain specificity while maximizing efficiency
  • Engineered a data cleaning pipeline in R to map, recode, and align all 30+ variables across the three datasets
  • Generated descriptive statstics for each variable to confirm choice of coding changes
