OpenClustered Package Expansion

Abstract: The original OpenClustered package addressed a need for a clustered data repository similar to OpenML or the Penn Machine Learning Benchmark for use in benchmark comparison studies. This repository decreases time spent finding, cleaning, and formatting data which often resulted wasted and duplicated efforts. It began with 19 publically available datasets with binary outcomes from various domains. This expansion to the OpenClustered package included the addition of 11 clustered datasets with continuous outcomes sourced from R packages, and package updates compatible with both classification and regression tasks.

  • Searched linear mixed model tutorials, R packages, and open-source data repositories for continuous clustered datasets with at least four features
  • Engineered an R pipeline for visualizing and summarizing the meta-data characteristics - number of observations, number of features, number of clusters, imbalance
  • Presented to a faculty, peers, researcheres across the domains of biomedical engineering, bioinformatics, biostatistics, and machine learning
